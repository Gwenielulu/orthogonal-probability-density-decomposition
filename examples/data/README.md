# SQG example field

`sqg_snapshot.npy` contains one channel from a two-layer surface quasi-geostrophic trajectory on a periodic (256 \times 256) grid. The snapshot is output index 950 from trajectory 0001 after the simulation spin-up and is stored as a two-dimensional `float32` array.

The single snapshot is included to reproduce the two-dimensional OPT example without distributing the full trajectory dataset.
